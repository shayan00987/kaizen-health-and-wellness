# Kaizen Health & Wellness

## Folder structure

- `index.html` - website page
- `styles.css`, `chatbot.css` - page and chatbot styles
- `script.js`, `chatbot.js` - page and chatbot behavior
- `assets/` - logo, hero image, and illustrations

## Deploy to Cloudflare Pages

Upload this folder directly to Cloudflare Pages, or connect its GitHub repository. No build command is needed; set the output directory to the project root (`.`).
